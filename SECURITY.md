# Security policy

Please don't report security problems in a public issue.

Report them privately through GitHub instead: on
https://github.com/DaDosDude/Fedigest, open the **Security** tab and choose
**Report a vulnerability**. Include what's affected, how to reproduce it,
and which version you run (shown in the site's footer).

Fixes go into the newest release; there are no separate maintained older
versions.
